# 快谱 Studio

一个本地网页原型，用来快速输入简谱、同步查看五线谱、切换乐器音色并导出 MIDI。

## 打开

直接用浏览器打开 `index.html` 即可。

## 当前功能

- 无空格简谱输入
- 简谱预览
- 五线谱 SVG 预览
- 谱面分页，每页可显示 4、6 或 8 小节
- 播放时自动跳转到当前音所在页
- 调号选择
- 中音萨克斯、次中音萨克斯、高音萨克斯、钢琴、吉他、电吉他、贝斯、小号音色
- 播放、暂停、继续、停止
- 循环播放
- 低八度播放
- MIDI 导出
- 在线采样音源优先，网络不可用时回退到内置合成

## 输入约定

- `1`：一拍 1
- `1.`：半拍 1
- `1-`：两拍 1
- `1--`：三拍 1
- `1+`：升 1
- `1b` 或 `1↓`：降 1
- `1*`：高八度 1
- `1/`：低八度 1
- `0`：休止一拍
- `0.`：休止半拍
- `0-`：休止两拍
- `|`：分小节

可以连续写，不需要空格：

```text
1231|235-|6/123|2---|
1.2.3.5.65|321-|561*2*|3*-2*1*|
1+2+3+5|1b2b3b5|
```

说明：`1-` 已经用于延长到两拍，所以降音用 `1b` 或 `1↓`，这样字符流解析不会冲突。

## 音色说明

页面会优先加载 WebAudioFont 的采样音源。第一次切换到某个乐器时需要联网加载一次，之后会缓存在当前页面内存中。若加载失败，仍会使用本地 WebAudio 合成音色播放。

管乐播放会额外加入很轻的连续气柱层，并让相邻音符有短交叠，目的是减少采样音逐个触发时的断裂感。
